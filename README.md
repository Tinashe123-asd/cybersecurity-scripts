# Security & Automation Scripts

A collection of lightweight security tools and Python scripts designed for network reconnaissance and security testing.

## Included Tools

* **`port_scanner.py`**: A multi-threaded socket-based Python script that scans standard ports (21, 22, 80, 443, 8080) on a target IP address to check for active services.

## Setup & Prerequisites

* Python 3.x installed on your system.
* Built-in standard libraries (`socket`, `sys`, `datetime`).

## Usage

Run the port scanner:
```bash
python3 port_scanner.py
